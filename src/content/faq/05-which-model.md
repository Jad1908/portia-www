It is a configuration knob, and every turn states what it is about to spend
before it starts.

The discipline behind the default is worth stating, because it shapes the
engine: development happens on a **cheap, small model at low effort**. If the
loop works there, what is good is the engine rather than the model, and a
frontier model becomes a ceiling check instead of a dependency. Keeping the loop
token-lean falls out of the same rule — the copilot sees compact profiles and
schemas, never raw data, which is what has to be true at real scale anyway.
