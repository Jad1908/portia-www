Not yet — it is pre-launch and there is no download. What is built and what is
still a direction, stated plainly rather than blurred:

- `built` &nbsp; The engine — checks, operations, specs, the catalog — on DuckDB
  throughout
- `built` &nbsp; The copilot loop: layered context, a tool ladder, questions
  routed to a human, spec writing
- `built` &nbsp; The three-pane app, and a full run with no terminal
- `built` &nbsp; SQL as the artifact — one committed `.sql` per spec, dbt-shaped
- `built` &nbsp; The knowledge graph and column-level lineage
- `built` &nbsp; Multi-turn conversation, with chat and indexing histories kept
  apart
- `vision` &nbsp; Warehouse and cloud-hosted projects — a UI vision before it is
  a mechanism, and nothing about it is scheduled
- `vision` &nbsp; Collaboration and multiple users — portia is project-local
  today, with no central store and nothing that aggregates across projects
